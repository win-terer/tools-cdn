# tools-cdn

[**Winterer's Tools**](https://tools.winterer.dev) — 미니토치DB(토치라이트 인피니트)와
미니히시즈DB(히어로시즈) — 가 쓰는 **정적 파일 보관소**입니다.
jsDelivr 가 이 저장소를 그대로 받아 서빙합니다.

```
https://cdn.jsdelivr.net/gh/win-terer/tools-cdn@<커밋>/tli/builder2/builder2.js
```

## 왜 따로 있나

사이트는 Cloudflare Workers 에 올라가 있는데, **한국에서 들어오면 미국 거점으로 붙습니다.**
2026-10-12 에 재 보니 압축 720KB 짜리 데이터 파일이 **10~24초**, 작은 파일도 첫 응답이 1~4초였습니다.
같은 파일을 jsDelivr 는 0.1초 안에 줍니다. 그래서 **화면(HTML)은 우리 서버에서, 그 화면이 부르는
js·css·데이터는 여기서** 받게 나눴습니다.

CDN 이 응답하지 않으면 각 페이지가 알아서 우리 서버 쪽 파일로 되돌아가므로, 이 저장소가 멈춰도
사이트는 느려질 뿐 깨지지 않습니다.

## 알아 두실 것

- **소스가 아니라 결과물입니다.** 사람이 읽으라고 만든 코드가 아니고, 빌드·생성 과정도 여기 없습니다
- **커밋 메시지가 전부 `sync`** 인 이유는 배포 스크립트가 자동으로 올리기 때문입니다. 커밋 하나가
  의미 있는 변경 하나를 뜻하지 않습니다
- **주소를 직접 걸지 마세요.** 파일 경로와 내용은 예고 없이 바뀝니다. 링크는 커밋 번호로 고정해
  쓰고 있어서, 최신(`@main`) 으로 걸면 어느 날 깨집니다
- 게임 데이터(아이템·스킬·옵션 이름과 수치)의 **권리는 각 게임사**에 있습니다. 여기 있는 것은
  그것을 사이트에서 쓰려고 가공해 둔 형태입니다
